# 个人 IP 身份提取规范

> 本文件定义「从上传照片 → 提取固定身份 → 生成一张手绘个人 IP 图」的标准流程。
> 服务端在收到照片后内部执行，买家无需阅读。

## 输入要求

- 至少一张人物清晰、轮廓完整、五官可辨认的照片。
- 优先正面或轻微侧面的全身/半身照；只有半身照时补全下装需向买家说明。
- 多张照片可用于身份复核，但不要把不同人的特征混合。
- 需要角色昵称（可选，仅用于成品文件名）。

**原始照片是人物身份的唯一来源。不要根据审美偏好擅自改变年龄感、肤色、体型、发型、服装类型或显眼配件。**

## 先提取固定身份（内部记录）

- 脸型与头部比例。
- 五官大小、位置和整体神态。
- 发型、发际线、发色和头发轮廓。
- 肤色、年龄感和体型轮廓。
- 固定服装的版型、颜色和主要结构。
- 鞋子、眼镜、手表、首饰等实际存在的配件及佩戴位置。
- 整体气质与适合保留的辨识点。

**只描述视觉事实，不猜测姓名、职业、民族、健康、政治、宗教、性取向或其他敏感属性。**

## 输出：一张手绘个人 IP 图

生成一张竖版单人物像（半身或全身），规则：

- 身份特征严格来自照片（脸型、发型、发际线、肤色、年龄感、体型、服装、鞋子、配件、比例一致）。
- 画风采用买家所选的手绘风格（见 风格库.md），不写实、不 3D、不二次元。
- 纯白或浅色背景，无标题、无边框、无四视图、无说明文字。
- 只改变动作、姿态、朝向、视线与轻微表情；不改变固定身份。
- 不复制原照片背景、其他人物、水印或文字。

## 质量检查（服务端自检）

- 脸型、发型、发际线、肤色、年龄感是否保留。
- 服装、鞋子、配件与佩戴位置是否一致。
- 是否错误复制了原照片背景、其他人物、水印或文字。
- 画风是否统一为所选手绘风格（未漂移成写实或 3D）。
- 一次付费只出一张图，不批量、不拼图。

任何一项明显失败时，重新生成一次再返回，不要返回低质量图。
